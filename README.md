I'm a Full Stack Developer based in Sri Lanka, working at the intersection of solid backend architecture and clean, usable frontends. My day-to-day lives in **.NET Core** and **Angular**, but I'm actively expanding into the **MERN stack and cloud infrastructure** — because the best engineers stay curious.

- 🔭 Currently building enterprise-grade systems (HRM, payroll, inventory, POS)
- 🌱 Leveling up in **MERN Stack**, **Cloud Deployment**, and **DevOps**
- 🏗️ Passionate about **Clean Architecture** and thoughtful system design
- 🎯 Long-term goal: ship software that's scalable, maintainable, and actually delightful to use
